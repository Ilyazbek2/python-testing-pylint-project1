

# Python Testing and Code Quality

A Python project demonstrating unit testing, static code analysis,
shell automation, and continuous integration.

## Features

- Python function with documentation
- Unit tests using unittest
- Multiple test scenarios using subTest
- Pylint code-quality checks
- Automated check.sh script
- JSON Pylint report
- GitHub Actions workflow

## Requirements

- Python 3.10+
- pip
- Git
- Bash

## Installation

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
